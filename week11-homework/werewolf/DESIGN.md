# 狼人杀游戏系统设计文档

## 项目概述

基于 LangChain + LangGraph 框架开发的狼人杀游戏系统，使用 DeepSeek 大模型实现 AI 智能体协作游戏。

## 架构设计

### 技术栈选择

| 组件 | 选择 | 理由 |
|------|------|------|
| Agent 框架 | LangChain + LangGraph | 流程可控性强，易于集成 RAG 与记忆模块 |
| LLM 模型 | DeepSeek-Chat | 性价比高，中文支持好 |
| 向量数据库 | FAISS | 轻量级，无需额外服务，适合本地开发 |
| 日志系统 | Rich + JSON | 终端输出美观，便于游戏回放 |

## 模块说明

### 1. 游戏状态管理 (`game/state.py`)

**核心类：**
- `GameState`: 中央游戏状态管理器
- `Player`: 玩家数据模型
- `GamePhase`: 游戏阶段枚举
- `Role`: 角色枚举

**功能：**
- 管理玩家状态（存活/死亡）
- 跟踪游戏阶段流转
- 记录投票和事件
- 判断胜负条件

### 2. 记忆管理系统 (`memory/manager.py`)

**核心类：**
- `MemoryManager`: 记忆存储和检索
- `Memory`: 单条记忆数据结构

**记忆类型：**
1. **情景记忆 (Episodic)**: 具体事件记录
   - 谁说了什么
   - 谁被怀疑过
   - 投票结果

2. **语义记忆 (Semantic)**: 抽象知识
   - 角色身份
   - 游戏规则理解
   - 策略总结

3. **工作记忆 (Working)**: 当前上下文
   - 本轮讨论
   - 当前观察

**RAG 应用：**
- 使用 FAISS 向量索引存储记忆嵌入
- 语义相似度检索相关历史
- 支持按玩家、重要程度过滤

### 3. Agent 实现 (`agents/`)

#### PlayerAgent (`player.py`)

每个 AI 玩家是一个独立的 Agent，具有：

**核心能力：**
- 角色扮演（狼人/村民）
- 性格特质（激进/谨慎/观察/魅力/多疑/平衡）
- 记忆管理
- 推理和决策

**主要方法：**
```python
async def night_discussion()    # 狼人夜间讨论
async def night_vote()           # 狼人夜间投票
async def day_speech()           # 白天发言
async def day_vote()             # 白天投票
```

#### ModeratorAgent (`moderator.py`)

游戏主持人，负责：
- 游戏流程控制
- 阶段转换
- 结果公布
- 胜负判定

### 4. Prompt 工程 (`prompts/templates.py`)

**Prompt 策略：**

1. **角色身份 Prompt**：定义角色目标和约束
2. **性格特质 Prompt**：注入行为风格
3. **记忆上下文**：动态插入相关记忆
4. **阶段特定 Prompt**：针对不同游戏阶段

**示例结构：**
```
系统提示 = 基础身份 + 性格特质 + 记忆上下文 + 当前局势
任务提示 = 阶段特定指令 + 可用信息 + 输出格式要求
```

## RAG 在决策链中的作用

### 1. 记忆检索
在发言和投票前，Agent 检索相关历史记忆：
- 按语义相似度检索
- 按玩家筛选
- 按重要程度筛选

### 2. 上下文构建
将检索到的记忆组织成上下文：
```
=== Recent Memories ===
- [10:30] 玩家4说：我是好人
- [10:35] 玩家5发言支支吾吾

=== Important Memories ===
- 玩家3在第二轮投票中投给了已知的村民
```

### 3. 推理增强
LLM 基于检索到的记忆进行推理：
- 发现矛盾点
- 识别可疑行为
- 制定指控策略

## 调试方法

### 1. 日志系统
- 游戏日志 JSON 文件
- 终端彩色输出
- 事件追踪

### 2. 记忆检查
```python
# 查看某个玩家的记忆
agent.memory.get_recent_memories(n=10)
agent.memory.get_context_string()
```

### 3. 成本追踪
每次 LLM 调用记录：
- Token 使用量
- 调用次数
- 预估成本

### 4. 可视化追踪
- Thought（思考）
- Action（行动）
- Observation（观察）

## 配置说明

### 环境变量 (.env)
```bash
DEEPSEEK_API_KEY=your_api_key
DEEPSEEK_BASE_URL=https://api.deepseek.com/v1
DEEPSEEK_MODEL=deepseek-chat
```

### 玩家配置
在 `main.py` 中修改：
- 玩家数量
- 角色分配
- 性格特质

## 扩展建议

1. **更多角色**：预言家、女巫、猎人等
2. **更复杂记忆**：使用 Milvus 替代 FAISS
3. **可视化界面**：Streamlit 展示游戏
4. **多人游戏**：支持人类玩家加入
5. **复盘分析**：自动生成游戏复盘报告
